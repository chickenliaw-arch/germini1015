# 性別事件處理流程與期程管控互動網站

本專案為針對校園「性別事件處理流程」設計的手機專用互動式網頁應用程式（Mobile-First Web App）。具備多案件期程管控、燈號警示長條圖、四階段流程視覺化與調查專業人才庫檢索功能。

---

## 🌟 功能亮點

1. **📱 手機直式版面設計 (Mobile-First UI)**
   - 專為智慧型手機最佳化，字體清晰適中（正文 $\ge 16\text{px}$），呈現明亮活潑色彩。
2. **⏱️ 法定管制期程自動計算與燈號監控**
   - **階段 1（3天）：** 校安通報與簽報評估。
   - **階段 2（20天）：** 性平會審議受理與否。
   - **階段 3（1個月，可展延+1個月）：** 調查小組完成調查報告。
   - **階段 4（2個月）：** 處理結果通知、申復與結案。
   - **三色警示長條圖：**
     - 🟢 **綠色：** 正常推動中。
     - 🔵 **藍色：** 警示（剩餘 3 天內即將到期）。
     - 🔴 **紅色：** 逾期警告。
3. **📁 多案件獨立管控**
   - 支援新增多個事件案號，個別獨立計算各階段截止日期與完成狀態。
4. **🔍 流程與人才庫快速檢索**
   - 內建四階段處理流程關鍵字搜尋與桃園市校園性別事件調查專業人才庫檢索。
5. **🔊 無外包依賴互動音效**
   - 採用瀏覽器原生 **Web Audio API**，點擊與狀態更新時提供即時音效反饋。
